# Nomre

📊 برنامه بررسی نمره با پایتون

این یک برنامه ساده برای بررسی نمره دانش‌آموز است که با زبان برنامه‌نویسی Python نوشته شده است.

برنامه یک عدد از کاربر دریافت می‌کند و با استفاده از دستورات شرطی، مشخص می‌کند که نمره واردشده در چه محدوده‌ای قرار دارد.

Game Rules / Program Conditions:

- 🔴 نمره بین ۰ تا کمتر از ۱۰: مردود!
- 🟡 نمره بین ۱۰ تا کمتر از ۱۵: متوسط!
- 🟢 نمره بین ۱۵ تا ۲۰: عالی!
- 🔵 نمره بیشتر از ۲۰: بیشتر از ۲۰!
- ⚠️ ورودی نامعتبر: خطا!

Results:

- اگر نمره کمتر از ۱۰ باشد، پیام "Mardood!" نمایش داده می‌شود.
- اگر نمره بین ۱۰ تا ۱۵ باشد، پیام "Motevaset!" نمایش داده می‌شود.
- اگر نمره بین ۱۵ تا ۲۰ باشد، پیام "Aalli!" نمایش داده می‌شود.
- اگر نمره بیشتر از ۲۰ باشد، پیام "More Than 20!" نمایش داده می‌شود.
- در غیر این صورت، پیام "Error!" نمایش داده می‌شود.

Python Concepts Used:

- Variables
- User Input ("input()")
- Integer Conversion ("int()")
- Conditional Statements ("if", "elif", "else")
- Comparison Operators ("<", ">=", "<=")
- Logical Operator ("and")

Goal: تمرین دستورات شرطی در پایتون و یادگیری نحوه بررسی محدوده اعداد با استفاده از عملگرهای مقایسه‌ای.
